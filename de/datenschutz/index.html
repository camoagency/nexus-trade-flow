Keine Cookies, kein Tracking

Diese Website setzt keine Cookies. Sie speichert nichts auf Ihrem Endgerät und liest nichts von dort aus. Es findet keine Analyse Ihres Nutzungsverhaltens statt. Es sind keine Tracking-Dienste, keine Werbenetzwerke, keine Karten und keine Social-Media-Plugins eingebunden.

Die verwendeten Schriften liegen auf dem Server dieser Website. Sie werden nicht von einem externen Anbieter geladen. Beim Aufruf einer Seite wird keine Verbindung zu einem Drittanbieter hergestellt. Der einzige Vorgang, bei dem Daten diese Website verlassen, ist das Absenden des Kontaktformulars.

Weil keine Informationen auf Ihrem Endgerät gespeichert oder ausgelesen werden, ist eine Einwilligung nach § 25 TDDDG nicht erforderlich. Deshalb finden Sie hier auch keinen Cookie-Banner.
