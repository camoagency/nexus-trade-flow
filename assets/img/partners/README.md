# Logos der Beschaffungsplattformen

Dieser Ordner ist vorbereitet, aber **absichtlich leer**.

Logodateien duerfen hier erst abgelegt und in `assets/js/partners.js` ueber das
Feld `logo` eingebunden werden, wenn eine **schriftliche Anweisung des Kunden**
vorliegt, dass Nexus Trade + Flow zur Darstellung dieser Marken berechtigt ist.

Fremde Wort-Bild-Marken auf einer gewerblichen Seite koennen Paragraf 14 MarkenG
und Paragraf 5 UWG beruehren, wenn sie eine Geschaeftsbeziehung nahelegen, die
nicht besteht.

Bis dahin laeuft die Sektion mit Textlinks. Diese Sperre nicht eigenmaechtig
aufloesen.
